# Void Walker

Jeu narratif d'horreur spatiale, jouable dans le navigateur, sur téléphone ou sur ordinateur.

Vous vous réveillez seul dans une station de transit désertée. Il faut en sortir.

## Jouer

**[Lancer le jeu](https://greffeb.github.io/void-walker/)**. Pas de compte, pas de téléchargement.

## Comment ça se joue

- Une partie dure environ 15 à 30 minutes.
- La partie est sauvegardée automatiquement.
- Une défaite termine la partie. On peut en lancer une nouvelle, mais la partie perdue reste perdue.
- Chaque partie se déroule dans une station différente.

## Installer le jeu sur votre téléphone

- **Android** (Chrome, Edge, Samsung Internet) : acceptez la proposition d'installation de la page, ou ouvrez le menu du navigateur et choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».
- **iPhone** (Safari) : touchez le bouton Partager, puis « Sur l'écran d'accueil ».

## Où en est le jeu

Le jeu est en développement (version 0.2.0). Certaines parties peuvent changer, et des bugs sont possibles.

## Pas de solution ici

Ce README ne donne ni solutions ni indices. Pour garder la surprise, n'ouvrez pas le dossier `docs/` : il contient le fond de l'histoire.

## Pour les curieux du code

Ce dépôt contient aussi le code du jeu, ses outils et ses documents de conception. Rien de tout cela n'est nécessaire pour jouer.

# Void Walker (English)

Narrative space horror game, playable in the browser, on phone or computer.

You wake up alone in a deserted transit station. You have to get out.

## Play

**[Launch the game](https://greffeb.github.io/void-walker/)**. No account, no download.

## How it works

- A game lasts about 15 to 30 minutes.
- The game saves automatically.
- A defeat ends the game. You can start a new one, but the lost game stays lost.
- Each game takes place in a different station.

## Install the game on your phone

- **Android** (Chrome, Edge, Samsung Internet): accept the install prompt on the page, or open the browser menu and choose "Install app" or "Add to Home screen".
- **iPhone** (Safari): tap the Share button, then "Add to Home Screen".

## Where the game stands

The game is in development (version 0.2.0). Some parts may change, and bugs are possible.
