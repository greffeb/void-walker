## Points de vigilance

Entrées que la spec implique sans qu'une tâche les exerce d'office. Chacune a son test dans la tâche indiquée.

1. **Partie enregistrée sur une station de L3** : elle doit se reconstruire identique. → Tâche 2. Valeurs relevées sur `main` avant tout changement, à la graine 2718281828 :
   - `empreinte` de l'objet `{ [id]: empreinte(monde) }` des 88 compositions publiées de L3, dans l'ordre de la liste : `152494a91b63a3` ;
   - `m08-m09-m06-embarquement` : `147ebc16edcecc` ;
   - `m10-m09-m03-entrepot` : `137409808e604c` ;
   - `m07-m10-m06-soute` : `0a4e45868f1f76`.
2. **`?station=` d'une composition possible mais rejetée par le vérifieur** (`m01-m03-palier-1`, `m02-m06-atelier-1`) : refus « non prouvée : non proposée », sans exception. Elle n'est jamais tirée. → Tâche 2.
3. **Deux pièces de même nom affiché sans lettre** dans une station publiée, par exemple « atelier maintenance » et « atelier » de M-08 : les noms affichés doivent rester distincts, sur les 328 stations publiées environ. → Tâche 2, en étendant le test de L3 s'il existe, sinon en l'ajoutant.
4. **Panneau vu du mauvais côté :** arrivé au quai de M-05 par la salle de tri, avant toute découverte, le menu ne propose pas le panneau. Depuis le local de service, il se voit fermé, sans destination. → Tâche 3.
5. **Bloc d'énergie ramené vers un passage étroit,** grille de M-02 ou panneau de M-05 : « aller » est indisponible, trop large, et un essai est refusé sans coût. → Tâche 4.
