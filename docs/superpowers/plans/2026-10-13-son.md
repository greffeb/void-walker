# Son : bruitages du terminal et ambiance — plan d'implémentation

> **Pour les agents :** sous-compétence requise : superpowers:subagent-driven-development (recommandée) ou superpowers:executing-plans, tâche par tâche. Les étapes se cochent (`- [ ]`).

**Goal :** chaque geste de l'interface a son bruit de terminal, quatre signaux doublent la santé, le feu, le vide et IA Station, un fond de bruit brun et une carlingue qui travaille installent la station ; trois rails règlent le tout ; aucun son avant le premier toucher, pause en arrière-plan, jamais d'erreur si l'audio manque.

**Architecture :** tout vit dans `app/son/`. Les recettes (`recettes.ts`) et la carlingue (`carlingue.ts`) sont des données et des tirages purs ; `declencheurs.ts` compare deux observations du moteur ; `moteur.ts` est le seul fichier qui touche à l'audio du navigateur, avec un contexte audio, un hasard et une minuterie fournis (faux dans les tests). Les écrans marquent chaque bouton d'un attribut `data-son` ; un seul écouteur, à la racine de `App`, en déduit le son du toucher (`contexte.ts`). L'App calcule les signaux après chaque action ; l'écran de jeu les annonce avec le crépitement de l'écriture.

**Tech Stack :** TypeScript strict (`noUncheckedIndexedAccess`, `verbatimModuleSyntax`, `noImplicitOverride`), React 19, Web Audio API, Vitest à globales (rendu `react-dom/server`), Playwright pour les captures, `npm run verify`.

**Spec :** [docs/15-son.md](../../15-son.md) ; décisions D-216 à D-222 de [docs/03-decisions.md](../../03-decisions.md). Les valeurs exactes des sons viennent du [banc](../../maquette/banc-sons.html), qui fait foi.

## Global Constraints

- `app/` importe app, engine et content ; `engine/` et `content/` ne changent pas ; la CLI non plus (15 §6).
- Aucun fichier son ajouté (D-216). `Math.random` est interdit partout par le lint (AP-02) : le hasard du moteur est fourni (`Dependances.hasard`) ; `app/main.tsx` lui passe un générateur rapide amorcé une fois par `crypto.getRandomValues`, sans lien avec le hasard de la partie.
- Gestes : `clic`, `bulle`, `fermer`, `panneau-inventaire`, `panneau-carte`, `panneau-ia`, `confirmer`, `refus`. Signaux : `alarme-feu`, `alarme-vide`, `blessure`, `blessure-critique`, `soin`, `ia`, joués dans cet ordre (15 §2.4).
- Un toucher, un son (D-217) : chaque `<button>` de `app/` porte `data-son` ; le son le plus précis remplace le clic.
- Signaux espacés de 250 ms entre la fin de l'un et le début du suivant ; ils attendent la fin du crépitement (500 ms, `DUREE_ECRITURE_MS`) ou partent dès qu'on le saute (15 §2.4).
- Gain = (niveau / 100)², niveau de 0 à 100 entier ; défauts général 80, effets 80, ambiance 30 (D-220) ; fondu de réglage 30 ms.
- Carlingue : un son toutes les 20 à 60 s, poids gémissement 2, craquement 2, pression 2, gong 1 (D-219).
- Aucun son avant le premier toucher ; caché : pause en bloc, crépitement et signaux en attente abandonnés, carlingue annulée ; montré : reprise (D-222). Audio absent ou en panne : muet, aucune erreur ne remonte (15 §5).
- Commentaires en français avec la référence (« 15 §2.2 », « D-218 »). Messages de commit « #99 : … », terminés par la ligne `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` ; description de PR terminée par la ligne de génération de la session.
- Zone orange : `npm run verify` vert, relecture indépendante, captures de la section SON, version de test ; fusion seulement avec l'accord du porteur ; « validation humaine requise » (D-129). Ne jamais écrire qu'une validation humaine a eu lieu.
- Branche `conception/99-son` (la conception y est déjà committée), comme les livraisons de la carte sur `conception/97-carte`.

```ts
// Sons du terminal en données (15 §3) : aucun audio ici. Valeurs du banc d'écoute (docs/maquette/banc-sons.html), qui fait foi.

export type Onde = 'square' | 'sine' | 'triangle' | 'sawtooth';
export type Filtre = 'bandpass' | 'lowpass' | 'highpass';

/** Oscillateur (15 §3.1) ; temps et durées en secondes depuis le départ du son, `vol` : niveau crête avant les bus. */
export interface Ton {
  readonly sorte: 'ton';
  readonly t: number;
  readonly duree: number;
  readonly f: number;
  /** Fréquence atteinte en fin de son, par glissement exponentiel. */
  readonly fin?: number;
  /** Carré par défaut. */
  readonly onde?: Onde;
  readonly vol: number;
  readonly passeBas?: number;
  /** Modulation d'amplitude carrée, en Hz (bourdonnement). */
  readonly trem?: number;
  readonly montee?: number;
  readonly chute?: number;
}

/** Bruit blanc filtré (15 §3.1) ; passe-bande et Q 1 par défaut. */
export interface Souffle {
  readonly sorte: 'souffle';
  readonly t: number;
  readonly duree: number;
  readonly f: number;
  readonly q?: number;
  readonly filtre?: Filtre;
  readonly vol: number;
  readonly montee?: number;
  readonly chute?: number;
}

export type ElementSon = Ton | Souffle;
export type Recette = readonly ElementSon[];

/** Montée : 2 ms pour un ton, 1 ms pour un souffle, sauf mention (15 §3.1). */
export function monteeDe(element: ElementSon): number {
  return element.montee ?? (element.sorte === 'ton' ? 0.002 : 0.001);
}

/** Chute : min(30 ms, durée / 2), sauf mention (15 §3.1). */
export function chuteDe(element: ElementSon): number {
  return element.chute ?? Math.min(0.03, element.duree / 2);
}

export function dureeRecette(recette: Recette): number {
  return recette.reduce((fin, element) => Math.max(fin, element.t + element.duree), 0);
}

export function decaler(recette: Recette, de: number): ElementSon[] {
  return recette.map((element) => ({ ...element, t: element.t + de }));
}

/** Gestes de l'interface (15 §2.1, D-217) : la valeur de l'attribut `data-son` des boutons. */
export const GESTES = ['clic', 'bulle', 'fermer', 'panneau-inventaire', 'panneau-carte', 'panneau-ia', 'confirmer', 'refus'] as const;
export type Geste = (typeof GESTES)[number];

/** Signaux du terminal (15 §2.2, D-218), dans l'ordre où ils se jouent (15 §2.4). */
export const SIGNAUX = ['alarme-feu', 'alarme-vide', 'blessure', 'blessure-critique', 'soin', 'ia'] as const;
export type Signal = (typeof SIGNAUX)[number];

export function ordonnerSignaux(signaux: readonly Signal[]): Signal[] {
  return SIGNAUX.filter((signal) => signaux.includes(signal));
}

/** Silence entre la fin d'un signal et le début du suivant (15 §2.4). */
export const ESPACE_SIGNAUX = 0.25;

/** Plafond commun des niveaux crête des bruitages (15 §7). */
export const VOLUME_MAX = 0.6;

const ton = (t: number, duree: number, f: number, autres: Partial<Omit<Ton, 'sorte' | 't' | 'duree' | 'f'>> & { readonly vol: number }): Ton => ({
  sorte: 'ton',
  t,
  duree,
  f,
  ...autres,
});

const souffle = (t: number, duree: number, f: number, autres: Partial<Omit<Souffle, 'sorte' | 't' | 'duree' | 'f'>> & { readonly vol: number }): Souffle => ({
  sorte: 'souffle',
  t,
  duree,
  f,
  ...autres,
});

/** Bip feutré des trois boutons de navigation, à la hauteur de chacun (15 §3.2). */
export const HAUTEURS_PANNEAU = { inventaire: 1.19, carte: 0.84, ia: 1 } as const;

const bipFeutre = (hauteur: number): Recette => [ton(0, 0.09, 660 * hauteur, { onde: 'sine', fin: 720 * hauteur, vol: 0.16, montee: 0.012, chute: 0.05 })];

const blessure = (hauteur: number): Recette => [
  souffle(0, 0.04, 700 * hauteur, { filtre: 'lowpass', q: 1, vol: 0.3 }),
  ton(0.02, 0.13, 220 * hauteur, { vol: 0.09, passeBas: 1500, trem: 40 }),
];

/** Bruitages des gestes (15 §2.1, §3.2). */
export const RECETTES_GESTES: Readonly<Record<Geste, Recette>> = {
  clic: [souffle(0, 0.007, 3600, { q: 2.5, vol: 0.55 }), ton(0, 0.004, 2400, { vol: 0.05 })],
  bulle: [souffle(0, 0.004, 3000, { q: 2.5, vol: 0.2 }), souffle(0.03, 0.004, 3600, { q: 2.5, vol: 0.16 })],
  fermer: [souffle(0, 0.004, 2400, { q: 2.5, vol: 0.18 })],
  'panneau-inventaire': bipFeutre(HAUTEURS_PANNEAU.inventaire),
  'panneau-carte': bipFeutre(HAUTEURS_PANNEAU.carte),
  'panneau-ia': bipFeutre(HAUTEURS_PANNEAU.ia),
  confirmer: [souffle(0, 0.006, 3600, { q: 2.5, vol: 0.35 }), ton(0.025, 0.045, 990, { onde: 'sine', vol: 0.08, montee: 0.004 })],
  refus: [0, 0.11].flatMap((de) => [ton(de, 0.07, 120, { vol: 0.12, passeBas: 1400 }), souffle(de, 0.07, 900, { q: 1.2, vol: 0.12 })]),
};

/** Signaux du terminal (15 §2.2, §3.2). */
export const RECETTES_SIGNAUX: Readonly<Record<Signal, Recette>> = {
  'alarme-feu': [0, 1, 2, 3, 4, 5].map((rang) => ton(rang * 0.09, 0.05, 1400, { vol: 0.06, chute: 0.01 })),
  'alarme-vide': [0, 0.26, 0.52].map((de) => ton(de, 0.16, 180, { vol: 0.14, passeBas: 1200, chute: 0.03 })),
  blessure: blessure(1),
  'blessure-critique': [...blessure(0.75), ...decaler(blessure(0.75), 0.32)],
  soin: [
    ton(0, 0.12, 523, { onde: 'sine', vol: 0.16, montee: 0.02, chute: 0.06 }),
    ton(0.12, 0.16, 784, { onde: 'sine', vol: 0.15, montee: 0.02, chute: 0.1 }),
  ],
  ia: [0, 0.07, 0.14].map((de) => ton(de, 0.028, 1600, { vol: 0.07 })),
};

/** Crépitement de l'écriture (15 §2.3, §3.2) : un tic tous les 36 ms × (0,75 à 1,25), sur une note tirée parmi trois. */
export const PAS_CREPITEMENT = 0.036;
export const NOTES_CREPITEMENT = [1200, 1500, 1800] as const;

export function crepitement(duree: number, hasard: () => number): Ton[] {
  const tics: Ton[] = [];
  for (let t = 0; t < duree; t += PAS_CREPITEMENT * (0.75 + hasard() * 0.5)) {
    const note = NOTES_CREPITEMENT[Math.min(NOTES_CREPITEMENT.length - 1, Math.floor(hasard() * NOTES_CREPITEMENT.length))] ?? NOTES_CREPITEMENT[0];
    tics.push(ton(t, 0.007, note, { onde: 'sine', vol: 0.07, chute: 0.004 }));
  }
  return tics;
}

/** Grain cassette des bruitages (15 §3.2) : saturation douce (tanh) puis passe-bas ; l'ambiance n'y passe pas. */
export const GRAIN = { saturation: 2.2, passeBas: 5200, q: 0.5 } as const;

/** Fond brun (15 §3.3) : bruit blanc stéréo de 9 s en boucle, deux passe-bas, gain 5, fondu d'entrée de 0,8 s. */
export const FOND = { duree: 9, filtres: [90, 260], q: 0.5, gain: 5, fondu: 0.8 } as const;
```

```ts
// Carlingue qui travaille (15 §3.4, D-219) : tirages purs, rendus par le moteur. Valeurs du banc d'écoute.

import type { Souffle } from './recettes';

export const GENRES = ['gemissement', 'craquement', 'pression', 'gong'] as const;
export type Genre = (typeof GENRES)[number];

/** Mélange : le gong deux fois plus rare que les autres (D-219). */
export const POIDS: Readonly<Record<Genre, number>> = { gemissement: 2, craquement: 2, pression: 2, gong: 1 };

/** Secondes entre deux sons de la carlingue (rythme rare). */
export const INTERVALLE = { min: 20, max: 60 } as const;

/** Réverbération de coque : réponse de 3,8 s, décroissance exp(−1,6 t), retour 0,9. */
export const COQUE = { duree: 3.8, decroissance: 1.6, retour: 0.9 } as const;

/** Un son de carlingue part 50 ms après sa programmation. */
export const DEPART_CARLINGUE = 0.05;

export interface Impulsion {
  readonly t: number;
  readonly amp: number;
}

/** Tôle qui frotte : impulsions dans des résonateurs, puis passe-bas et enveloppe (15 §3.4). */
export interface Frottement {
  readonly genre: 'gemissement' | 'craquement' | 'pression';
  readonly duree: number;
  readonly impulsions: readonly Impulsion[];
  /** Durée d'une impulsion, en secondes. */
  readonly grain: number;
  readonly resonateurs: readonly number[];
  readonly q: number;
  readonly passeBas: number;
  readonly vol: number;
  /** Part du son envoyée sans réverbération. */
  readonly direct: number;
  readonly pan: number;
  /** Coup sourd au départ de la pression : sinus de `de` à `a` Hz en `glisse` s. */
  readonly coup?: { readonly de: number; readonly a: number; readonly glisse: number; readonly duree: number; readonly vol: number };
}

/** Un coup de masse loin sur la coque. */
export interface Gong {
  readonly genre: 'gong';
  readonly base: number;
  readonly partiels: readonly { readonly rapport: number; readonly niveau: number; readonly duree: number }[];
  /** Chaque partiel est joué deux fois, à ± `desaccord` × rapport Hz. */
  readonly desaccord: number;
  readonly niveau: number;
  readonly montee: number;
  readonly choc: Souffle;
  readonly passeBas: number;
  readonly direct: number;
  readonly pan: number;
}

export type Carlingue = Frottement | Gong;

const entre = (hasard: () => number, min: number, max: number): number => min + hasard() * (max - min);

export function choisirGenre(hasard: () => number): Genre {
  const total = GENRES.reduce((somme, genre) => somme + POIDS[genre], 0);
  let reste = hasard() * total;
  for (const genre of GENRES) {
    reste -= POIDS[genre];
    if (reste < 0) return genre;
  }
  return 'gong';
}

export function intervalle(hasard: () => number): number {
  return entre(hasard, INTERVALLE.min, INTERVALLE.max);
}

/** La tôle accroche, glisse, accroche : `cadence(u)` impulsions par seconde, u de 0 à 1 ; au moins 0,5 par seconde. */
export function frottement(duree: number, cadence: (u: number) => number, hasard: () => number): Impulsion[] {
  const impulsions: Impulsion[] = [];
  for (let t = 0; t < duree; ) {
    impulsions.push({ t, amp: entre(hasard, 0.4, 1) });
    t += (1 / Math.max(0.5, cadence(t / duree))) * entre(hasard, 0.7, 1.3);
  }
  return impulsions;
}

const panoramique = (hasard: () => number): number => entre(hasard, -0.75, 0.75);

function gemissement(hasard: () => number): Frottement {
  const duree = entre(hasard, 2.2, 3.6);
  const bas = entre(hasard, 7, 10);
  const haut = entre(hasard, 16, 26);
  const hauteur = entre(hasard, 0.85, 1.2);
  return {
    genre: 'gemissement',
    duree,
    impulsions: frottement(duree, (u) => bas + (haut - bas) * Math.sin(Math.PI * u) + entre(hasard, -2, 2), hasard),
    grain: 0.0012,
    resonateurs: [180, 297, 431, 612].map((frequence) => frequence * hauteur),
    q: 22,
    passeBas: 1400,
    vol: 36,
    direct: 0.4,
    pan: panoramique(hasard),
  };
}

function craquement(hasard: () => number): Frottement {
  const duree = entre(hasard, 0.5, 1.1);
  const hauteur = entre(hasard, 0.8, 1.25);
  return {
    genre: 'craquement',
    duree,
    impulsions: frottement(duree, () => entre(hasard, 3, 14), hasard),
    grain: 0.0008,
    resonateurs: [520, 1310, 2380].map((frequence) => frequence * hauteur),
    q: 35,
    passeBas: 2800,
    vol: 75,
    direct: 0.3,
    pan: panoramique(hasard),
  };
}

function pression(hasard: () => number): Frottement {
  const duree = entre(hasard, 3, 4.5);
  return {
    genre: 'pression',
    duree,
    impulsions: frottement(duree, (u) => 4 + 6 * u + entre(hasard, -1, 1), hasard),
    grain: 0.002,
    resonateurs: [70, 113, 182, 260].map((frequence) => frequence * entre(hasard, 0.9, 1.1)),
    q: 30,
    passeBas: 700,
    vol: 150,
    direct: 0.4,
    pan: panoramique(hasard),
    coup: { de: 48, a: 34, glisse: 1.4, duree: 1.5, vol: 1 },
  };
}

function gong(hasard: () => number): Gong {
  return {
    genre: 'gong',
    base: entre(hasard, 55, 82),
    partiels: [
      { rapport: 1, niveau: 1, duree: 5.5 },
      { rapport: 1.48, niveau: 0.7, duree: 4.2 },
      { rapport: 2.15, niveau: 0.55, duree: 3.4 },
      { rapport: 2.71, niveau: 0.4, duree: 2.6 },
      { rapport: 3.6, niveau: 0.25, duree: 1.9 },
      { rapport: 4.93, niveau: 0.12, duree: 1.3 },
    ],
    desaccord: 0.25,
    niveau: 0.6,
    montee: 0.012,
    choc: { sorte: 'souffle', t: 0, duree: 0.05, f: 260, filtre: 'lowpass', q: 0.7, vol: 2.5 },
    passeBas: entre(hasard, 1000, 1400),
    direct: 0.35,
    pan: panoramique(hasard),
  };
}

const TIRAGES: Readonly<Record<Genre, (hasard: () => number) => Carlingue>> = { gemissement, craquement, pression, gong };

export function tirerCarlingue(hasard: () => number): Carlingue {
  return TIRAGES[choisirGenre(hasard)](hasard);
}

/** Durée du son, réverbération non comprise. */
export function dureeCarlingue(son: Carlingue): number {
  if (son.genre === 'gong') return Math.max(...son.partiels.map((partiel) => partiel.duree));
  return Math.max(son.duree, son.coup?.duree ?? 0);
}
```

```ts
// Signaux du terminal après une action (15 §2.2, D-218) : on compare ce que le passager voit avant et après.

import type { Observation, Sante } from '../../engine';
import type { Signal } from './recettes';

const GRAVITE: Readonly<Record<Sante, number>> = { indemne: 0, blesse: 1, critique: 2, vaincu: 3 };

/**
 * Une alarme sonne quand le feu ou le vide passe d'absent à présent dans la pièce du passager : il y entre, ou le danger s'y
 * propage ; rester dans le danger ne la fait pas resonner, y revenir si. Résultat dans l'ordre de jeu (15 §2.4).
 */
export function signauxApres(avant: Observation, apres: Observation): Signal[] {
  const signaux: Signal[] = [];
  const memePiece = avant.piece.id === apres.piece.id;
  if (apres.feu && !(memePiece && avant.feu)) signaux.push('alarme-feu');
  if (apres.sansAir && !(memePiece && avant.sansAir)) signaux.push('alarme-vide');
  const ecart = GRAVITE[apres.sante] - GRAVITE[avant.sante];
  if (ecart > 0) signaux.push(GRAVITE[apres.sante] >= GRAVITE.critique ? 'blessure-critique' : 'blessure');
  if (ecart < 0) signaux.push('soin');
  if (apres.messages.length > avant.messages.length) signaux.push('ia');
  return signaux;
}
```

```ts
function fausseMinuterie() {
  const attentes: { readonly ms: number; readonly quoi: () => void; annulee: boolean }[] = [];
  return {
    attentes,
    attendre(ms: number, quoi: () => void): () => void {
      const attente = { ms, quoi, annulee: false };
      attentes.push(attente);
      return () => {
        attente.annulee = true;
      };
    },
    actives() {
      return attentes.filter((attente) => !attente.annulee);
    },
    /** Déclenche la plus ancienne attente active qui convient. */
    declencher(convient: (ms: number) => boolean = () => true): number {
      const attente = attentes.find((candidate) => !candidate.annulee && convient(candidate.ms));
      if (attente === undefined) throw new Error('Aucune attente active.');
      attente.annulee = true;
      attente.quoi();
      return attente.ms;
    },
  };
}
```

```ts
function courbeSaturation(k: number): Float32Array<ArrayBuffer> {
  const courbe = new Float32Array(1024);
  for (let i = 0; i < courbe.length; i += 1) {
    const x = (i * 2) / courbe.length - 1;

function bruitBlanc(ctx: BaseAudioContext, duree: number, hasard: () => number): AudioBuffer {
  const tampon = ctx.createBuffer(2, Math.ceil(ctx.sampleRate * duree), ctx.sampleRate);
  for (let canal = 0; canal < 2; canal += 1) {
    const donnees = tampon.getChannelData(canal);

  }
  return tampon;

/** Réverbération de coque (15 §3.4) : bruit de plus en plus sombre, décroissance exp(−1,6 t). */
function reponseCoque(ctx: BaseAudioContext, hasard: () => number): AudioBuffer {
  const longueur = Math.ceil(ctx.sampleRate * COQUE.duree);
  const tampon = ctx.createBuffer(2, longueur, ctx.sampleRate);
  for (let canal = 0; canal < 2; canal += 1) {
    const donnees = tampon.getChannelData(canal);
    let sombre = 0;
    for (let i = 0; i < longueur; i += 1) {
      const t = i / ctx.sampleRate;
      const lissage = 0.25 + 0.7 * (t / COQUE.duree);
      sombre += (hasard() * 2 - 1 - sombre) * (1 - lissage);
      donnees[i] = sombre * Math.exp(-t * COQUE.decroissance);
    }
  }
  return tampon;
}

function tamponFrottement(ctx: BaseAudioContext, son: Frottement, hasard: () => number): AudioBuffer {
  const taux = ctx.sampleRate;
  const longueur = Math.max(1, Math.ceil(taux * son.duree));
  const tampon = ctx.createBuffer(1, longueur, taux);
  const donnees = tampon.getChannelData(0);
  const grain = Math.max(1, Math.floor(son.grain * taux));
  for (const { t, amp } of son.impulsions) {
    const debut = Math.floor(t * taux);
    for (let i = 0; i < grain && debut + i < longueur; i += 1) {
      donnees[debut + i] = (donnees[debut + i] ?? 0) + (hasard() * 2 - 1) * amp * Math.exp(-i / (grain / 3));
    }
  }
  return tampon;
}

function enveloppe(ctx: BaseAudioContext, t: number, duree: number, vol: number, montee: number, chute: number): GainNode {
  const gain = ctx.createGain();
  gain.gain.setValueAtTime(SILENCE_GAIN, t);
  gain.gain.exponentialRampToValueAtTime(vol, t + montee);
  gain.gain.setValueAtTime(vol, Math.max(t + montee, t + duree - chute));
  gain.gain.exponentialRampToValueAtTime(SILENCE_GAIN, t + duree);
  return gain;
}

export function creerMoteur(deps: Dependances, niveauxDeDepart: Niveaux): Son {
  let niveaux = niveauxDeDepart;
  let bus: Bus | null = null;
  /** Audio absent ou en panne : plus rien n'est tenté, le jeu reste muet (15 §5). */
  let enPanne = false;
  let visible = true;
  let fond: AudioBufferSourceNode | null = null;
  let annulerCarlingue: (() => void) | null = null;
  let ecriture: { readonly sources: AudioScheduledSourceNode[]; readonly annuler: () => void } | null = null;
  let enAttente: readonly Signal[] = [];

  const audible = (couche: 'effets' | 'ambiance'): boolean => bus !== null && visible && niveaux.general > 0 && niveaux[couche] > 0;

  function couperTout(): void {
    const arrets: (() => void)[] = [
      () => ecriture?.annuler(),
      () => annulerCarlingue?.(),
      () => fond?.stop(),
      () => {
        void bus?.ctx.close().catch(rien);
      },
    ];
    for (const arreter of arrets) {
      try {
        arreter();
      } catch {
        // Déjà en panne : on se tait.
      }
    }
    ecriture = null;
    annulerCarlingue = null;
    fond = null;
    enAttente = [];
  }

  function sur(quoi: () => void): void {
    if (enPanne) return;
    try {
      quoi();
    } catch {
      enPanne = true;
      couperTout();
    }
  }

  function monter(ctx: AudioContext): Bus {
    const general = ctx.createGain();
    general.connect(ctx.destination);
    const effets = ctx.createGain();
    effets.connect(general);
    const grain = ctx.createGain();
    const ambiance = ctx.createGain();
    ambiance.connect(general);
    const saturation = ctx.createWaveShaper();
    saturation.curve = courbeSaturation(GRAIN.saturation);
    saturation.oversample = '2x';
    const bande = filtre(ctx, 'lowpass', GRAIN.passeBas, GRAIN.q);
    grain.connect(saturation);
    saturation.connect(bande);
    bande.connect(effets);
    const coque = ctx.createConvolver();
    coque.buffer = reponseCoque(ctx, deps.hasard);
    const retour = ctx.createGain();
    retour.gain.value = COQUE.retour;
    coque.connect(retour);
    retour.connect(ambiance);
    return { ctx, general, effets, grain, ambiance, coque, bruit: bruitBlanc(ctx, FOND.duree, deps.hasard) };
  }

  function appliquerNiveaux(b: Bus, fondu: boolean): void {
    const reglages: [GainNode, number][] = [
      [b.general, niveaux.general],
      [b.effets, niveaux.effets],
      [b.ambiance, niveaux.ambiance],
    ];
    for (const [noeud, niveau] of reglages) {
      if (fondu) noeud.gain.setTargetAtTime(gainDe(niveau), b.ctx.currentTime, FONDU_REGLAGE);
      else noeud.gain.value = gainDe(niveau);
    }
  }

  function jouerElement(b: Bus, element: ElementSon, depart: number, vers: AudioNode, sources: AudioScheduledSourceNode[] = []): void {
    const { ctx } = b;
    const t = depart + element.t;
    const gain = enveloppe(ctx, t, element.duree, element.vol, monteeDe(element), chuteDe(element));
    const fin = t + element.duree + 0.02;
    if (element.sorte === 'ton') {
      const oscillateur = ctx.createOscillator();
      oscillateur.type = element.onde ?? 'square';
      oscillateur.frequency.setValueAtTime(element.f, t);
      if (element.fin !== undefined) oscillateur.frequency.exponentialRampToValueAtTime(element.fin, t + element.duree);
      if (element.passeBas === undefined) oscillateur.connect(gain);
      else {
        const passeBas = filtre(ctx, 'lowpass', element.passeBas);
        oscillateur.connect(passeBas);
        passeBas.connect(gain);
      }
      if (element.trem === undefined) gain.connect(vers);
      else {
        // Bourdonnement : amplitude modulée en carré entre 0 et 1.
        const lfo = ctx.createOscillator();
        lfo.type = 'square';
        lfo.frequency.value = element.trem;
        const profondeur = ctx.createGain();
        profondeur.gain.value = 0.5;
        const porte = ctx.createGain();
        porte.gain.value = 0.5;
        lfo.connect(profondeur);
        profondeur.connect(porte.gain);
        gain.connect(porte);
        porte.connect(vers);
        lfo.start(t);
        lfo.stop(fin);
        sources.push(lfo);
      }
      oscillateur.start(t);
      oscillateur.stop(fin);
      sources.push(oscillateur);
      return;
    }
    const lecteur = ctx.createBufferSource();
    lecteur.buffer = b.bruit;
    lecteur.loop = true;
    const passe = filtre(ctx, element.filtre ?? 'bandpass', element.f, element.q ?? 1);
    lecteur.connect(passe);
    passe.connect(gain);
    gain.connect(vers);
    lecteur.start(t, deps.hasard() * (FOND.duree - 1));
    lecteur.stop(fin);
    sources.push(lecteur);
  }

  function jouerRecette(b: Bus, recette: Recette, depart: number, sources?: AudioScheduledSourceNode[]): void {
    for (const element of recette) jouerElement(b, element, depart, b.grain, sources);
  }

  /** Les signaux en attente partent l'un après l'autre (15 §2.4). */
  function liberer(): void {
    const liste = ordonnerSignaux(enAttente);
    enAttente = [];
    const b = bus;
    if (b === null || !audible('effets')) return;
    let t = b.ctx.currentTime + DEPART;
    for (const signal of liste) {
      const recette = RECETTES_SIGNAUX[signal];
      jouerRecette(b, recette, t);
      t += dureeRecette(recette) + ESPACE_SIGNAUX;
    }
  }

  /** Arrête le crépitement en cours ; `true` s'il y en avait un. */
  function arreterEcriture(): boolean {
    if (ecriture === null) return false;
    const { sources, annuler } = ecriture;
    ecriture = null;
    annuler();
    for (const source of sources) source.stop();
    return true;
  }

  function programmerCarlingue(): void {
    annulerCarlingue?.();
    annulerCarlingue = deps.minuterie.attendre(intervalle(deps.hasard) * 1000, () => {
      annulerCarlingue = null;
      sur(() => {
        const b = bus;
        if (b === null || fond === null || !audible('ambiance')) return;
        jouerCarlingue(b, tirerCarlingue(deps.hasard));
        programmerCarlingue();
      });
    });
  }

  function demarrerAmbiance(b: Bus): void {
    const lecteur = b.ctx.createBufferSource();
    lecteur.buffer = b.bruit;
    lecteur.loop = true;
    let dernier: AudioNode = lecteur;
    for (const frequence of FOND.filtres) {
      const passeBas = filtre(b.ctx, 'lowpass', frequence, FOND.q);
      dernier.connect(passeBas);
      dernier = passeBas;
    }
    const gain = b.ctx.createGain();
    const t = b.ctx.currentTime;
    gain.gain.setValueAtTime(SILENCE_GAIN, t);
    gain.gain.exponentialRampToValueAtTime(FOND.gain, t + FOND.fondu);
    dernier.connect(gain);
    gain.connect(b.ambiance);
    lecteur.start(t);
    fond = lecteur;
    programmerCarlingue();
  }

  function arreterAmbiance(): void {
    annulerCarlingue?.();
    annulerCarlingue = null;
    if (fond === null) return;
    const lecteur = fond;
    fond = null;
    lecteur.stop();
  }

  function jouerCarlingue(b: Bus, son: Carlingue): void {
    const { ctx } = b;
    const t = ctx.currentTime + DEPART_CARLINGUE;
    const pan = ctx.createStereoPanner();
    pan.pan.value = son.pan;
    const direct = ctx.createGain();
    direct.gain.value = son.direct;
    pan.connect(direct);
    direct.connect(b.ambiance);
    pan.connect(b.coque);
    if (son.genre === 'gong') {
      const entree = ctx.createGain();
      const passeBas = filtre(ctx, 'lowpass', son.passeBas);
      entree.connect(passeBas);
      passeBas.connect(pan);
      for (const partiel of son.partiels) {
        for (const ecart of [-son.desaccord, son.desaccord]) {
          const oscillateur = ctx.createOscillator();
          oscillateur.type = 'sine';
          oscillateur.frequency.value = son.base * partiel.rapport + ecart * partiel.rapport;
          const gain = ctx.createGain();
          gain.gain.setValueAtTime(SILENCE_GAIN, t);
          gain.gain.exponentialRampToValueAtTime(partiel.niveau * son.niveau, t + son.montee);
          gain.gain.exponentialRampToValueAtTime(SILENCE_GAIN, t + partiel.duree);
          oscillateur.connect(gain);
          gain.connect(entree);
          oscillateur.start(t);
          oscillateur.stop(t + partiel.duree + 0.05);
        }
      }
      jouerElement(b, son.choc, t, entree);
      return;
    }
    const lecteur = ctx.createBufferSource();
    lecteur.buffer = tamponFrottement(ctx, son, deps.hasard);
    const somme = ctx.createGain();
    for (const frequence of son.resonateurs) {
      const resonateur = filtre(ctx, 'bandpass', frequence, son.q);
      lecteur.connect(resonateur);
      resonateur.connect(somme);
    }
    const passeBas = filtre(ctx, 'lowpass', son.passeBas);
    const gain = ctx.createGain();
    gain.gain.setValueAtTime(SILENCE_GAIN, t);
    gain.gain.exponentialRampToValueAtTime(son.vol, t + son.duree * 0.25);
    gain.gain.setValueAtTime(son.vol, t + son.duree * 0.6);
    gain.gain.exponentialRampToValueAtTime(SILENCE_GAIN, t + son.duree);
    somme.connect(passeBas);
    passeBas.connect(gain);
    gain.connect(pan);
    lecteur.start(t);
    if (son.coup === undefined) return;
    const coup = ctx.createOscillator();
    coup.type = 'sine';
    coup.frequency.setValueAtTime(son.coup.de, t);
    coup.frequency.exponentialRampToValueAtTime(son.coup.a, t + son.coup.glisse);
    const gainCoup = ctx.createGain();
    gainCoup.gain.setValueAtTime(SILENCE_GAIN, t);
    gainCoup.gain.exponentialRampToValueAtTime(son.coup.vol, t + 0.03);
    gainCoup.gain.exponentialRampToValueAtTime(SILENCE_GAIN, t + son.coup.duree);
    coup.connect(gainCoup);
    gainCoup.connect(b.coque);
    gainCoup.connect(b.ambiance);
    coup.start(t);
    coup.stop(t + son.coup.duree + 0.1);
  }

  return {
    debloquer() {
      sur(() => {
        if (bus === null) {
          const ctx = deps.creerContexte();
          if (ctx === null) {
            enPanne = true;
            return;
          }
          bus = monter(ctx);
          appliquerNiveaux(bus, false);
        }
        if (!visible) return;
        if (bus.ctx.state !== 'running') void bus.ctx.resume().catch(rien);
        if (fond === null && audible('ambiance')) demarrerAmbiance(bus);
      });
    },
    geste(geste) {
      sur(() => {
        if (bus === null || !audible('effets')) return;
        jouerRecette(bus, RECETTES_GESTES[geste], bus.ctx.currentTime + DEPART);
      });
    },
    nouveauTexte(ecrit, signaux) {
      sur(() => {
        // Un texte arrivé pendant l'écriture du précédent : les signaux de celui-ci partent d'abord.
        if (arreterEcriture()) liberer();
        enAttente = signaux;
        if (bus === null || !ecrit || deps.mouvementReduit() || !audible('effets')) {
          liberer();
          return;
        }
        const sources: AudioScheduledSourceNode[] = [];
        jouerRecette(bus, crepitement(DUREE_ECRITURE_MS / 1000, deps.hasard), bus.ctx.currentTime + DEPART, sources);
        const annuler = deps.minuterie.attendre(DUREE_ECRITURE_MS, () =>
          sur(() => {
            ecriture = null;
            liberer();
          }),
        );
        ecriture = { sources, annuler };
      });
    },
    taire() {
      sur(() => {
        if (arreterEcriture()) liberer();
      });
    },
    regler(nouveaux) {
      niveaux = nouveaux;
      sur(() => {
        if (bus === null) return;
        appliquerNiveaux(bus, true);
        if (!audible('ambiance')) arreterAmbiance();
        else if (fond === null) demarrerAmbiance(bus);
      });
    },
    cacher() {
      visible = false;
      sur(() => {
        arreterEcriture();
        enAttente = [];
        annulerCarlingue?.();
        annulerCarlingue = null;
        if (bus !== null) void bus.ctx.suspend().catch(rien);
      });
    },
    montrer() {
      visible = true;
      sur(() => {
        if (bus === null) return;
        void bus.ctx.resume().catch(rien);
        if (!audible('ambiance')) return;
        if (fond === null) demarrerAmbiance(bus);
        else if (annulerCarlingue === null) programmerCarlingue();
      });
    },
  };
}
```

```ts
/** Taille du texte : récit à 17, 19 ou 22 px, le reste à proportion (12 §4.10). */
export const TAILLES = ['standard', 'grande', 'tres_grande'] as const;
export type Taille = (typeof TAILLES)[number];

export interface Reglages {
  readonly taille: Taille;
  /** « Lignes de balayage » [OUI] / [NON] (12 §2.3). */
  readonly balayage: boolean;
  /** « Effet machine à écrire » [OUI] / [NON]. */
  readonly machineAEcrire: boolean;
  /** Rails du son, de 0 à 100 (15 §4, D-220). */
  readonly general: number;
  readonly effets: number;
  readonly ambiance: number;
}

export const CLE_REGLAGES = 'void-walker:reglages';

export const REGLAGES_PAR_DEFAUT: Reglages = { taille: 'standard', balayage: true, machineAEcrire: true, general: 80, effets: 80, ambiance: 30 };

/** Niveau de 0 à 100, arrondi ; illisible : sa valeur par défaut. */
function niveau(valeur: unknown, defaut: number): number {
  return typeof valeur === 'number' && Number.isFinite(valeur) ? Math.round(Math.min(100, Math.max(0, valeur))) : defaut;
}

/** Réglages enregistrés ; un réglage illisible ou absent prend sa valeur par défaut. */
export function lireReglages(lire: (cle: string) => string | null): Reglages {
  try {
    const brut: unknown = JSON.parse(lire(CLE_REGLAGES) ?? 'null');
    if (typeof brut !== 'object' || brut === null) return REGLAGES_PAR_DEFAUT;
    const { taille, balayage, machineAEcrire, general, effets, ambiance } = brut as Record<string, unknown>;
    return {
      taille: TAILLES.find((connue) => connue === taille) ?? REGLAGES_PAR_DEFAUT.taille,
      balayage: balayage !== false,
      machineAEcrire: machineAEcrire !== false,
      general: niveau(general, REGLAGES_PAR_DEFAUT.general),
      effets: niveau(effets, REGLAGES_PAR_DEFAUT.effets),
      ambiance: niveau(ambiance, REGLAGES_PAR_DEFAUT.ambiance),
    };
  } catch {
    return REGLAGES_PAR_DEFAUT;
  }
}
```

```ts
// Son dans React (15 §6) : les écrans disent quel geste a eu lieu, jamais comment il sonne.

import { createContext, useContext } from 'react';
import { SILENCE, type Son } from './moteur';
import { GESTES, type Geste, type Signal } from './recettes';

export const SonContexte = createContext<Son>(SILENCE);

export function useSon(): Son {
  return useContext(SonContexte);
}

/** Élément touché, vu par `closest` : un élément du navigateur, ou dans les tests un objet qui l'imite. */
interface Touche {
  readonly tagName?: string;
  closest(selecteur: string): { getAttribute(nom: string): string | null } | null;
}

/**
 * Son d'un toucher (15 §2.1) : le `data-son` de l'élément touché ou de son plus proche parent. Un champ ne sonne pas : toucher
 * l'étiquette d'un segment fait aussi cliquer son bouton radio, qui sonnerait une seconde fois ; un rail sonne au relâché.
 */
export function sonDuToucher(cible: unknown): Geste | null {
  if (typeof cible !== 'object' || cible === null || !('closest' in cible)) return null;
  const element = cible as Touche;
  if (element.tagName === 'INPUT') return null;
  const valeur = element.closest('[data-son]')?.getAttribute('data-son');
  return GESTES.find((geste) => geste === valeur) ?? null;
}

const annonces = new WeakSet<object>();

/** Annonce un texte affiché une seule fois, même si l'effet se rejoue (mode strict, retour des options) (15 §2.3, §2.4). */
export function annoncerTexte(son: Son, texte: object, ecriture: boolean, signaux: readonly Signal[]): void {
  if (annonces.has(texte)) return;
  annonces.add(texte);
  son.nouveauTexte(ecriture, signaux);
}
```

```tsx
const TOUCHES_RAIL = new Set(['ArrowLeft', 'ArrowRight', 'ArrowUp', 'ArrowDown', 'Home', 'End', 'PageUp', 'PageDown']);

/**
 * Rail du son (15 §4, D-220) : libellé, détail, valeur à droite (« COUPÉE » ou « COUPÉS » à 0), puis le curseur natif.
 * Le réglage s'applique pendant le glissé ; le clic de contrôle part au relâché, au nouveau niveau.
 */
function Rail({
  libelle,
  detail,
  coupe,
  valeur,
  changer,
}: {
  readonly libelle: string;
  readonly detail?: string;
  readonly coupe: string;
  readonly valeur: number;
  readonly changer: (valeur: number) => void;
}) {
  const id = useId();
  const son = useSon();
  const ecrite = valeur === 0 ? coupe : String(valeur);
  return (
    <div className="rail">
      <label className="rail-haut" htmlFor={id}>
        <span>
          {libelle}
          {detail !== undefined && <span className="detail-option">{detail}</span>}
        </span>
        <span className="valeur-rail" aria-hidden="true">
          {ecrite}
        </span>
      </label>
      <input
        id={id}
        className="curseur-rail"
        type="range"
        min={0}
        max={100}
        step={1}
        aria-valuetext={valeur === 0 ? coupe.toLowerCase() : String(valeur)}
        style={{ '--rempli': `${valeur}%` } as CSSProperties}
        value={valeur}
        onChange={(evenement) => changer(Number(evenement.currentTarget.value))}
        onPointerUp={() => son.geste('clic')}
        onKeyUp={(evenement) => {
          if (TOUCHES_RAIL.has(evenement.key)) son.geste('clic');
        }}
      />
    </div>
  );
}
```

```ts
/**
 * Son (15 §5, D-222), dans Chromium : un espion compte les contextes audio et les sources créés. Aucun contexte avant le
 * premier toucher ; un seul ensuite ; ouvrir une bulle fait partir des sons. Niveau « vérifié automatiquement ».
 */
async function verifierSon(navigateur: Browser, adresse: string, erreurs: string[]): Promise<void> {
  const contexte = await navigateur.newContext({ ...devices[TELEPHONE], viewport: REFERENCE, locale: 'fr-FR' });
  await contexte.addInitScript(() => {
    const compte = { contextes: 0, sources: 0 };
    (window as unknown as { __sons: typeof compte }).__sons = compte;
    const Vrai = window.AudioContext;
    window.AudioContext = class extends Vrai {
      constructor(options?: AudioContextOptions) {
        super(options);
        compte.contextes += 1;
      }
      override createOscillator(): OscillatorNode {
        compte.sources += 1;
        return super.createOscillator();
      }
      override createBufferSource(): AudioBufferSourceNode {
        compte.sources += 1;
        return super.createBufferSource();
      }
    };
  });
  const page = await contexte.newPage();
  const compte = (): Promise<{ contextes: number; sources: number }> =>
    page.evaluate(() => (window as unknown as { __sons: { contextes: number; sources: number } }).__sons);
  try {
    await page.goto(adresse);
    await page.getByRole('button', { name: /^nouvelle partie$/i }).waitFor();
    if ((await compte()).contextes !== 0) erreurs.push('Son : un contexte audio existe avant le premier toucher.');
    await nouvelleDepuisAccueil(page);
    const apres = await compte();
    if (apres.contextes !== 1) erreurs.push(`Son : ${apres.contextes} contexte(s) audio après les premiers touchers, 1 attendu.`);
    await page.locator('.dock .puce[aria-haspopup="dialog"]').first().click();
    if ((await compte()).sources <= apres.sources) erreurs.push('Son : ouvrir une bulle ne fait partir aucun son.');
  } finally {
    await contexte.close();
  }
}
```
