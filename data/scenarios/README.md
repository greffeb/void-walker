# Generated Scenarios

This directory contains all successfully generated scenarios from Void Walker.

## File Format

Each scenario file is saved in JSON format with the following naming convention:
```
{scenario_title}_{timestamp}.json
```

Example: `Le_Dernier_Signal_20251204_153045.json`

## Structure

Each scenario file contains:
- **Metadata**: Title, setting type, premise, main threat
- **Locations**: All game locations with descriptions, connections, items, and secrets
- **NPCs**: Non-player characters with their attributes and behaviors
- **Victory Condition**: How the player can win the scenario
- **Secrets**: Hidden story elements and discoveries
- **Environmental Clues**: Atmospheric details and hints
- **Validation Data**: Critical path and design notes

## Usage

These scenarios can be:
- Reviewed for quality and balance
- Replayed in future sessions
- Modified and customized
- Used as templates for new scenarios
- Analyzed for pattern detection and improvement

## Timestamps

All scenario files include:
- `_saved_at`: When the scenario was generated
- `_scenario_name`: Original scenario title
- Generated on date in filename (YYYYMMDD_HHMMSS format)
